# Минное поле

Приложение Flutter / Material 3 с русским интерфейсом. Исходные требования
сохранены в `README.md`.

## Запуск

Нужен Flutter stable с Dart >= 3.8 (разработка: Flutter 3.47.7).

```sh
flutter pub get
flutter run -d chrome
```

Для Android: установите Android SDK, примите лицензии через
`flutter doctor --android-licenses`, подключите устройство или эмулятор и выполните
`flutter run`. Наличие Flutter само по себе не означает готовность Android SDK.
Для публикации Android-приложения настройте собственную подпись release:
сейчас используется стандартная отладочная подпись шаблона Flutter.

```sh
flutter analyze
flutter test
flutter build web --no-web-resources-cdn
```

`dart tool/check_game.dart` дополнительно проверяет правила на 300 полях
без внешних зависимостей. Это не заменяет Flutter-тесты интерфейса и хранения.

## В этой облачной среде

```sh
export PATH="/workspace/tools/flutter/bin:$PATH"
export XDG_CONFIG_HOME=/workspace/.local-config
export PUB_CACHE=/workspace/.pub-cache
export ANALYZER_STATE_LOCATION_OVERRIDE=/workspace/.analyzer-state
export FLUTTER_SUPPRESS_ANALYTICS=true
export DART_SUPPRESS_ANALYTICS=true
export CI=true
flutter pub get
flutter run -d web-server --web-hostname=0.0.0.0 --web-port=8080
```

Или используйте `./scripts/flutterw pub get` и
`./scripts/flutterw run -d web-server --web-hostname=0.0.0.0 --web-port=8080`:
обёртка устанавливает эти параметры автоматически в облачной среде.

SDK скачивается с `storage.googleapis.com`, пакеты — с `pub.dev`.
В ограниченной среде оба домена должны быть разрешены. Команда `flutter doctor`
покажет необязательные для веба отсутствующие Android/Linux инструменты.

## Правила и сохранение

- Новичок: 9×9, 10 мин; любитель: 12×12, 24 мины; эксперт: 16×16, 50 мин.
- Первый ход и окружающие его клетки безопасны.
- Нажатие открывает клетку; удерживание или режим «Флажки» ставит флаг.
- Нажатие числа раскрывает соседей, если рядом поставлено нужное число флагов.
  Ошибочно поставленные флаги могут привести к поражению.
- Поле поддерживает перемещение и масштабирование, в том числе на телефоне.
- Для победы нужно открыть все безопасные клетки. Таймер запускается первым
  открытием и останавливается при уходе с поля или сворачивании приложения.
- Победа: `max(100, число_мин × 1000 − секунды × 5)` очков.
  Поражение: `открытые_клетки × 10` очков.
- Поле, время и флажки автоматически сохраняются локально через
  `shared_preferences`. Кнопка «Продолжить» восстанавливает партию.
- История содержит последние 200 завершённых игр. Рекорды показывают пять
  лучших времён побед для выбранной сложности среди сохранённых игр.
- В браузере данные привязаны к адресу сайта и профилю. Очистка данных сайта,
  приватный режим или другое устройство не сохраняют историю между сеансами.

## Структура

- `lib/game.dart` — независимые от интерфейса правила и сериализация поля.
- `lib/storage.dart` — локальное сохранение и история, последовательная запись.
- `lib/main.dart` — меню, поле, результат, рекорды и анимации переходов.
- `test/` — тесты правил, сохранения и навигации.
