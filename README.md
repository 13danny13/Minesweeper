создай приложение на flutter:
1. Минимум 2–3 экрана
 • меню/главный экран (старт или список);
 • основной экран - игровое поле;
 • дополнительный экран (результаты / настройки).
 2. Хранение данных
 • сохранение состояния игры (счёт).
 3. Интерактивность
 • пользователь должен влиять на процесс (ходы в игре).
 4. Навигация
 • переход между экранами (меню → игра → результат).
 5. UI и UX
 • оформление в стиле Material Design;
 • приложение выглядит как завершённое (не набор кнопок).
 6. Анимация / визуальные эффекты
 • хотя бы одна анимация (плавный переход экрана).
7. Таблица рекордов, сохранение истории игр.
8. Уровни сложности.
